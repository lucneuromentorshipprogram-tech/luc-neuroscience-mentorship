HOW TO ADD THIS TO YOUR WEBSITE (GitHub/Vercel)
1. Open the GitHub repository connected to your Vercel website.
2. Upload the files from this folder into the SAME top-level/root folder where index.html, resources.html, styles.css, script.js, and lnmp-logo.png are located.
3. Choose to replace the existing HTML files when GitHub asks. The updated files keep their original website filenames.
4. Do NOT replace styles.css, script.js, or lnmp-logo.png. The new page uses the existing shared files already in your project.
5. Commit the changes. Vercel should redeploy automatically.
6. After deployment, visit: https://www.lucneuromentorship.org/professional-development-resources.html

IMPORTANT
- Upload the PDF and the new HTML page together into the website root. The embedded viewer depends on the PDF being beside the HTML file.
- This package does not publish anything by itself; it only contains files for you to review and upload.
- PDF viewer height is 1,100 px on desktop, 950 px on medium screens, and 780 px on mobile. Users can scroll through all 16 pages and open the full PDF separately.
