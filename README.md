# LUC Neuroscience Mentorship Program — Final Website

Complete static multi-page redesign using the actual 2026–27 executive-board information and public photos already present on the existing program website.

Pages: Home, Executive Board, Mission, Resources, Events, Get Involved.

The resource/event links point to official Loyola pages. Application forms use mailto so visitors can prepare an email without a backend.

The site uses Loyola’s published maroon (#5a0722) and gold (#eaaa00) colors. The official Loyola logo is not embedded because Loyola’s current brand guidance says student organizations should not use University trademarks without authorization; the site instead uses “at Loyola University Chicago” naming.
